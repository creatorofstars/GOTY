Spine 分层素材包
================
来源：character one.png (Q版持枪男孩立绘)
画布：1536 x 1024 像素

文件清单（按 Spine 层级，从底到顶）：
  01_leg_back.png   后腿（远侧腿 + 靴子）
  02_leg_front.png  前腿（近侧腿 + 靴子）
  05_torso.png      躯干（白短袖上衣 + 蓝色牛仔裤腰段）
  09_hair_back.png  后层头发（可独立摆动）
  06_scarf.png      红色领巾
  04_belt_bag.png   棕色腰带 + 腰包
  08_head.png       头部整体（脸 + 前发 + 耳朵，3/4 侧面朝右）
  07_headband.png   红色头带（含骷髅标志和飘带尾）
  03_weapon.png     大型红色大炮（含握持的棕色手套和小段前臂）

使用说明：
- 所有部件均为带透明通道的 PNG。
- 导入 Spine 时建议新建 1536x1024 画布，按文件名前缀顺序从底到顶拖入。
- 由于部件由 AI 辅助分离，各自位置/比例已在预览中初步对齐，但仍需在 Spine
  中手动微调每个部件的轴心点（bone pivot）和位置。
- 绑骨建议：后发做独立骨可做摆动；头部整体做旋转骨；武器挂在前臂骨上。

已知限制：
- 前臂裸露段与护腕未能从原图中干净分离，已并入武器部件（连同手套）。
- 若需要更精细的手指/五官动画，建议在 Spine 中对头部做网格蒙皮或额外
  拆分眼部、嘴部等小部件。
